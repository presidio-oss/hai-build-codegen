# HAI Build Code Generator Documentation

Welcome to the documentation for HAI Build Code Generator, an intelligent VS Code extension designed to streamline development workflows through AI-powered task execution, intelligent file management, and automated code generation.

## Documentation Index

- [Getting Started](getting-started.md) - Learn how to set up the extension and get started.
- [Architecture Overview](architecture.md) - High-level understanding of how HAI Build is built.
- [Extension Overview](extension-overview.md) - Key components and core functionality.
- [MCP Integration](mcp-integration.md) - Details on Model Context Protocol (MCP) support.

## Project Structure

- `src/`: Core extension source code.
- `webview-ui/`: Frontend/UI implementation for the chat interface.
- `proto/`: Protocol buffer definitions.
- `tests/`: Test suite.
- `docs/`: This documentation.
